Forge

Local-first code editor for Windows · About / Privacy

Forge works only inside the folder you open. Everything else — preferences, session and recent folders — stays in a local userData directory. Python output and tracebacks never leave memory. There is no account, no sync and no telemetry.

Stored on this device

  • Recent folders — up to five absolute folder paths.
  • Session — the workspace root, open tab paths and cursor positions, saved in tab order.
  • Settings — theme, editor and tree font size, tab size, word wrap and whitespace visibility.
  • Python output — never stored. Lines, notices and paths exist only in the panel’s memory and disappear on Clear or app exit.
Location
The operating system’s userData directory for this account: C:\Users\Patrick\AppData\Roaming\Forge
Settings, session and recent folders are separate JSON files. File contents are never persisted.

Python runs stay local

  • No logs or JSON — run output, tracebacks, interpreter paths and workspace paths are never written to disk.
  • No artefacts — Run and Check syntax do not create __pycache__ folders or .pyc files.
  • No outbound request — file contents, interpreter details and process output are never sent over the network.
  • Explicit start — opening a file, switching tabs or asking for completion never starts a child process.

Nothing leaves this machine

Monaco, fonts and icons are bundled with the application. While Forge runs, it makes no HTTP or HTTPS request. External links are refused in the renderer; only a checked http(s) link can be passed to the operating system’s browser.

Deleting local data

Reset Local Data removes settings.json, session.json and recent-folders.json. Forge restarts at the Welcome screen with defaults. This cannot be undone.

Vendor details

Open Provider name, contact address and legal notice are still to be supplied by the vendor. These fields are intentionally not invented.
